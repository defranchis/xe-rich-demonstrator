`c4_dispersion_selection.py`: how much configuration 4 (proximity focusing) underestimates the ≥ 80 % ring rate because `cosmic_rates.py` selects the rings at one Cherenkov angle, that of the tile index n = 1.03 (its 400 nm value), while the photon yield uses the dispersive (single-pole) index. On the telescope muons of the Xe 2 bar plain-tile runs (`c4_xe2_g30/50/70_plain`) it recomputes the containment at n = 1.03, which must reproduce the run's selection, and with the dispersion (the containment averaged over 12 energies of the QE band with Frank–Tamm × S13361 weights at the muon's velocity), and prints, per gap, the ≥ 80 % ring rate of both and their paired relative change with its seed error. Run it on the output directory of a `cosmic_rates.py` run of group `c4` with the default detector inputs: `python studies/cosmic_rates.py --groups c4 --outdir RUN`, then `python scripts/investigations/config4_single_angle/c4_dispersion_selection.py RUN RUN/c4_dispersion_selection.txt [--ne 12 --nproc 4]`.
